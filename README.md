# software-engineering-journey

A personal repository documenting my path to becoming a full stack software engineer.

## About

I am learning software engineering step by step, building small projects to practice each concept. This repository keeps the history of my lessons, exercises, and projects.

## Contents

- `02-html/lessons/01-intro-html/`: my first HTML page about HTML itself.
- `02-html/projects/01-mi-entorno-de-desarrollo/`: a page that documents how I set up my development environment on Ubuntu.
- `professional-portfolio/`: my portfolio website, built with HTML and CSS.

## How to view a page

1. Open the project folder in VS Code.
2. Right-click the `index.html` file.
3. Select **Open with Live Server**.
