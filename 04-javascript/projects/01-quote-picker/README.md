# Quote Picker

A small web app that shows a new quote every time you click a button.

## How to view

1. Open the folder in VS Code.
2. Right-click `index.html` and choose **Open with Live Server**.

## What I practiced

- Arrays and the `.length` property
- Functions (`showQuote`)
- Events (clicks on the button)
- `if` to go back to the first quote
